# Thaer Media Website

موقع تعريفي ومعرض أعمال لـ Thaer Media (ثائر القريناوي). الموقع ثابت (Static) ومبني بـ HTML وCSS وJavaScript عادي، ولا يحتاج إلى تثبيت حزم أو خطوة بناء.

## الصفحات

| الرابط | الملف | المحتوى |
|---|---|---|
| `/` | `index.html` | الرئيسية: الخدمات، الأعمال، من نحن، طريقة العمل، آراء العملاء |
| `/contact/` | `contact/index.html` | صفحة التواصل ونموذج واتساب |
| `/socialmedia.courses1/` | `socialmedia.courses1/index.html` | صفحة الورشة التدريبية ونموذج التسجيل |
| `/work.social/` | `work.social/index.html` | معرض السوشيال ميديا |
| `/work.brand/` | `work.brand/index.html` | معرض الهويات البصرية |
| `/work.ads/` | `work.ads/index.html` | معرض نتائج الحملات الإعلانية |
| `/work.print/` | `work.print/index.html` | معرض المطبوعات |
| `/work.video/` | `work.video/index.html` | معرض صناعة المحتوى (فيديوهات قصيرة) |
| `/sponsor/` | `sponsor/index.html` | صفحة كفالة طالب (مستقلة، لا يوجد لها رابط داخل الموقع) |
| أي رابط غير موجود | `404.html` | صفحة «الصفحة غير موجودة» |

كل الصفحات تشترك في الهيدر والفوتر وزر واتساب العائم، وتدعم العربية والإنجليزية والوضعين الداكن والفاتح.

## تعديل المحتوى

- **أغلب المحتوى في `assets/js/data.js`**: رقم واتساب والبريد، حسابات التواصل، روابط القائمة، أرقام الخبرة، السلايدات، الخدمات، الأعمال، خطوات العمل، آراء العملاء، وصور المعارض.
- لكل نص نسختان `ar` و`en`. عدّل الاثنتين معاً.
- النصوص الثابتة الخاصة بكل صفحة (مثل العناوين) مكتوبة في ملف HTML الخاص بها داخل الخاصيتين `data-ar` و`data-en`. عدّل الخاصيتين **ونص العنصر نفسه** معاً.
- رقم واتساب يُكتب أرقاماً فقط مع رمز الدولة (مثل `970599351383`) في `contact.whatsappNumber` وفي رابط `socials`.

## إضافة أعمال للمعارض

1. استخدم أسماء ملفات **إنجليزية بلا مسافات** (مثل `23.jpg` أو `new-brand.jpg`). الأسماء العربية والمسافات تسبب صوراً مكسورة على بعض الاستضافات.
2. **السوشيال ميديا**: ارفع الصورة إلى `assets/gallery/social/` باسم رقمي جديد، وأضف رقمها في قائمة `socialOrder` أسفل `data.js`. يُفضّل أن تضع نسخة مصغّرة بعرض 640px وبنفس الاسم في `social/thumbs/`، وإن لم توجد تُستخدم الصورة الأصلية تلقائياً.
3. **الهوية والحملات**: أضف عنصراً إلى مصفوفة `gallery` في `data.js` بالشكل:
   `{ image: "assets/gallery/identity/name.jpg", alt: { ar: "وصف الصورة", en: "Image description" } }`
4. **المطبوعات**: لكل عمل صورتان: `cover` (الصورة في مكانها، بنسبة 4:3) و`image` (التصميم الأصلي).
5. **الفيديو (صناعة المحتوى)**: ضع الفيديو في `assets/gallery/video/` (عمودي 9:16، MP4) وغلافه في `assets/gallery/video/posters/` (1080×1920، والمحتوى الأساسي في منتصفه بمقاس 4:5 = 1080×1350 لأن البطاقة تقصّه بهذه النسبة)، ثم أضف عنصراً إلى `work.video.gallery` في `data.js`:
   `{ video: "assets/gallery/video/01.mp4", poster: "assets/gallery/video/posters/01.jpg", duration: "0:30", alt: { ar: "وصف", en: "Description" } }`
6. اكتب وصفاً حقيقياً في `alt`، فهو يظهر لمحركات البحث ولقارئات الشاشة.

## المعاينة محلياً

افتح المجلد في Visual Studio Code وشغّل إضافة **Live Server** من `index.html`، أو نفّذ داخل المجلد:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. لا تفتح الملفات مباشرة بصيغة `file://`، لأن روابط المجلدات لن تعمل.

## النشر

- ارفع محتوى المجلد كاملاً إلى جذر الاستضافة مع الحفاظ على أسماء المجلدات.
- بعد تعديل ملف CSS أو JS، غيّر رقم `?v=23` في روابط الملفات داخل صفحات HTML (مثلاً إلى `?v=24`) حتى يحصل الزوار على النسخة الجديدة بدل النسخة المخزنة.
- إذا غيّرت الدومين، حدّث الروابط التي تبدأ بـ `https://thaerdesigner.com` في وسوم `canonical` و`og:` داخل الصفحات، وفي `sitemap.xml` و`robots.txt`.

## ملاحظات

- نماذج التواصل والتسجيل لا ترسل بيانات إلى خادم. هي تجهّز رسالة واتساب، والزائر يكمل الإرسال من واتساب.
- خط **Expo Arabic** يُحمَّل حالياً من موقع خارجي (onlinewebfonts). إن كان لديك ترخيص للخط، يُنصح برفع ملفات الخط إلى مجلد `assets/fonts` وتعديل روابط `@font-face` أعلى `site.css`. وإن تعذّر تحميله يظهر الموقع تلقائياً بخط **IBM Plex Sans Arabic** البديل.

## صفحة كفالة طالب (`/sponsor/`)

صفحة مستقلة بتصميمها وملفاتها داخل مجلد `sponsor/`، ولا يوجد لها أي رابط داخل الموقع؛ يصل إليها فقط من معه الرابط `thaerdesigner.com/sponsor`. وهي مضافة إلى `sitemap.xml` لتظهر في محركات البحث.

- **كل الإعدادات في أعلى `sponsor/sponsor.js` داخل `CONFIG`**: مبالغ الكفالة، ورقم واتساب، والبريد، ووسائل الدفع.
- **وسائل الدفع**: لكل وسيلة إما `url` (رابط دفع مثل PayPal وPayoneer) أو حقول `value` تُنسخ بضغطة (رقم IBAN، محفظة USDT، بال باي، جوال باي، ...). الوسيلة التي بياناتها فارغة تظهر بزر «اطلب البيانات عبر واتساب». لإخفاء وسيلة اجعل `show: false`.
- **الصور**: صورة أعلى الصفحة `sponsor/photo.jpg` (طولية 4:5)، وصورة المدرب `sponsor/trainer.jpg` (طولية 3:4). استبدلهما بصور جديدة بنفس الاسم، أو غيّر `photo` و`trainerPhoto` في `CONFIG`.
- **صورة المعاينة عند مشاركة الرابط**: `sponsor/og.png` بمقاس 1200×800. عند استبدالها غيّر رقم `?v=` في رابطها داخل `sponsor/index.html`.
- بعد أي تعديل غيّر رقم `?v=` في رابطي `sponsor.css` و`sponsor.js` داخل `sponsor/index.html`.
